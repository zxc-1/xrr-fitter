# XRR Fitter

XRR Fitter is an X-ray reflectivity fitting application for Python 3.12 on
macOS arm64.

The supported Python boundary is `xrr_fitter.api`. Launch the desktop shell
with `xrr-fitter` or `python -m xrr_fitter`; use `--help` for command-line
usage. Development and verification commands are documented in `AGENTS.md`
and `docs/architecture/r23-clean-break.md`.
