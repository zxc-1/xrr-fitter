# XRR Fitter

XRR Fitter is an X-ray reflectivity fitting application for Python 3.12 on
macOS arm64.

The supported Python boundary is `xrr_fitter.api`. The installed application
entry points are added with the completed GUI implementation. Development and
verification commands are documented in `AGENTS.md` and
`docs/architecture/r23-clean-break.md`.
