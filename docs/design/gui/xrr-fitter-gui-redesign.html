反射率拟合工作台 — 重新设计预览

基于对项目实际能力的审计（xrr_fitter.api 公共接口、用户指南、以及全部 GUI 面板控件清单）， 抛开现有"中央图 + 自由停靠面板"的布局，围绕 科学工作流本身 重新组织界面。 这是一份静态高保真预览：所有图表为内联 SVG，所有字段名、单位、状态与置信度标签均与代码库一致。

信息架构：管线导航 + 自适应画布 + 上下文检视器 配色：Okabe-Ito 色觉友好（已过校验脚本） 显示单位：nm / g·cm⁻³ / Å⁻²（内部持久化 Å） 主题：明色为主，随系统明暗自适应

设计理念

为什么是"管线导航 + 自适应画布 + 检视器"

现有界面把每类信息都做成可自由拖动的停靠面板，灵活但缺少方向感——新手容易迷路，专家也要反复找面板。 XRR 分析本质是一条有向管线：导入 → 结构 → 参数 → 拟合 → 结果 → 导出。新设计把这条管线变成界面的主骨架， 让"我在哪一步、下一步能不能走"始终可见，同时保留专家所需的全部深度。

① 左栏 · 项目与管线

上半是数据集列表（带状态与置信度字形、可拟合计数）， 下半是竖向管线 stepper。两套模式（引导 / 专家）共享同一条管线，只是展开深度不同——它们是同一文档的两个投影，功能等价。

② 中央 · 自适应画布

随当前阶段切换主内容：结果态以对数反射率图 + 残差为主； 结构态显示可点击剖面 + SLD 深度剖面；拟合态显示九阶段进度与实时曲线。画布顶部一排 tab 承载同一阶段的多个视图。

③ 右栏 · 上下文检视器

永远回答"选中项的细节是什么"：结果态显示置信度报告 + 参数表 + 候选解； 结构态显示选中层编辑器。可折叠，让画布在需要时独占宽度。

④ 顶栏 · 命令 & 模式

项目命令（新建/打开/保存）、引导↔专家分段切换、主操作"一键拟合"、导出、明暗切换。 主操作在标准模式收敛为单按钮流；专家模式解锁独立/联合批量选择与手动拟合。

⑤ 底栏 · 状态

就绪态圆点 + 原因、拟合质量（置信度 · 目标值 J）、活动数据集、数据源校验状态； 拟合时叠加进度条。所有阻塞原因在此单行呈现，不打断主视图。

⑥ 无障碍与数据可视化

置信度/状态一律"形状/图标 + 文字"双编码，绝不单靠颜色；数值列用等宽数字（tabular figures）； ≥2 条序列必有图例并尽量直接标注；对比度达 4.5:1；焦点可见、可键盘导航。

取材真实：下列每一帧的控件、字段、单位与文案，均来自代码库审计，可与 gui/ 各面板逐一对应。
非照搬：布局骨架（管线主导航、检视器、自适应画布）是全新的，未沿用现有 dock 布局。

置信度体系 · 颜色 + 形状双重编码

● 可信 TRUSTED

参数唯一、置信区间收敛、无边界命中。可直接采信。

◆ 可用但相关 CORRELATED

解可用，但存在强参数相关；需结合 Profile 似然判读区间。

▲ 多解 MULTIPLE

存在多个目标值相近的候选，需人工在候选间裁决。

■ 不可信 UNTRUSTED

未收敛、命中边界或残差含系统性结构。不应采信。

○ 不可用 N/A

未纳入拟合或数据不足，无判定（回退态）。

对应能力：theme 令牌 · ConfidenceClass（TRUSTED/CORRELATED/MULTIPLE/UNTRUSTED + 回退）· 数据色相固定策略 · 双重编码可及性
