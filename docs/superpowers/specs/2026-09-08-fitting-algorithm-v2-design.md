# 拟合算法 V2：正确性、统计口径与性能设计

## 1. 已确认的范围

用户要求推进本轮审计的全部问题及优化建议，并明确没有旧项目。
本设计据此采用一次性新算法切换，不建设旧项目迁移、历史结果阅读器、兼容层或双算法实现。

- 基线：`main@c369ed0`。
- 新算法身份：`xrr-fit-v2`；目标函数版本：`2`；项目结构版本：`3`。
- 旧算法身份、旧项目结构和旧检查点明确拒绝，错误信息说明版本不支持，不尝试静默转换。
- 应用发行版本、tag 和发布操作不在本次范围；算法版本不等于应用发行版本。
- 保留 Parratt、现有解析导数、材料、分辨率、混合波长、足迹和界面物理定义。
- 不新增生产依赖，不改部署方式，不扩大现有 CI 门禁类型。
- 工作位于独立分支 `feat/fitting-algorithm-v2`，不修改其他工作树中的现有用户改动。

## 2. 方案取舍

采用分批实施的新版本单实现：每批具有独立的失败复现、修复和回归证据，最后统一验收。
不采用一次性重写物理和优化器，因为已经通过的物理参照不应被无关重写破坏。
不采用只修表面误报的热补丁，因为目标、导数、不确定度及导出之间的口径必须一起修正。

| O5 | 固定粗网格与固定预算不适应复杂条纹 | 根据条纹密度选择网格，使用完整网格复核和可重放的预算分配 |

## 4. 数值边界与数据流

继续遵守既有依赖图：`model` 保存值，`evaluation` 负责共享数值定义，`fit` 搜索，
`analysis` 推断，`services.fitting` 组合。`fit` 和 `analysis` 不相互导入。

- 单次模型求值必须保持：物理值与约束求导 → 有效拟合点上的物理模型 → 模式残差及 Jacobian → 数据项和先验项。
- 模型曲线、用于求解的残差、用于诊断的残差不是同一个概念，必须保留各自的单位和名称。
- log 模式诊断使用 log 残差，Gaussian 使用标准化残差，Poisson 使用有符号 deviance 残差。
- 非正强度不伪造 log 值；诊断与绘图只在相应变换定义域内显示该变换。
- 对模式不支持的输入显式报错，不能转回 robust-log 或更换数据意义。
- 用户排除的点不会因为切换噪声模式而自动重新启用。

## 5. 统一目标函数与噪声模式

把用于推断的总量记为 `Q`，把展示和排名用的每点量记为 `J = Q / N`。
`N` 是完整有效拟合数据点数，不是粗网格点数。

### 5.1 默认 robust-log

保留 robust-log 作为默认探索模式，保持区域平衡策略为显式的优化偏好：

```text
r_i = log10(M_i + floor) - log10(y_i + floor)
Q_data = sum_i 2 * w_i^2 * (sqrt(1 + (r_i / c)^2) - 1)
```

`c` 是显式声明的稳健尺度，不冒充仪器给出的强度测量误差。
区域权重形成的是加权稳健目标／伪似然；不因此宣称普通最大似然置信区间。
联合 robust-log 可保留数据集平衡，但实际权重必须进入数值证据和统计校准。

### 5.2 Gaussian 强度误差模式

```text
r_i = (M_i - y_i) / sigma_i
Q_data = sum_i r_i^2
```

要求每个拟合点具有有限、严格为正且与强度同单位的标准差。
不对该模式再施加等区域、等数据集的经验权重；独立观测的信息相加。
允许在模式定义域内处理零值和负的观测强度，不借用 log 模式的排除规则。

### 5.3 Poisson 原始计数模式

```text
k_i = raw_counts_i
mu_i = normalization * M_i
Q_data = 2 * sum_i (mu_i - k_i + k_i * log(k_i / mu_i))
```

`k_i = 0` 时其对数项按极限取零。正计数对应非正预测时明确拒绝候选。
用户必须显式选择原始计数模式；归一化强度、计数率或背景扣除后的数据不能自动视为计数。
首版要求未合并成分数的非负整数原始计数；不支持的计数语义在预检阶段说明。

### 5.4 尺度先验及完整导数

```text
z = log10(scale / scale_center) / tau
Q = Q_data + z^2
log_probability = -Q / 2 + explicit_mcmc_parameter_prior_terms
```

不重复添加尺度先验。已有显式参数先验仍标明其 MCMC 作用域，不能假装没有额外先验时才成立的恒等式对其也成立。
尺度先验导数直接通过尺度的完整物理 Jacobian 计算：

```text
dz/du = (dscale/du) / (scale * ln(10) * tau)
```

因此自由尺度、表达式约束尺度、联合共享尺度及多级约束都不依赖名称匹配特例。
平台估计属于从数据产生的弱约束，不能在统计说明中称为额外独立测量。
粗网格保留完整数据的平台中心、开关理由、宽度和 `N`；重采样则按其统计目标重新估计平台证据。

## 6. 协方差与联合诊断

### 6.1 单曲线

- Gaussian：使用标准化残差的总信息矩阵，而不是平均展示损失的逆矩阵。
- Poisson：使用计数模型的期望信息；零计数、低计数和边界解有独立验证。
- robust-log：使用稳健 sandwich 估计；强自相关下优先移动块 bootstrap，不把 iid 近似包装成相关噪声下的已校准误差。
- 用 SVD 检查秩与病态性。不可辨识方向显示“不可估计”，不得用伪逆的零值宣称零误差。
- 无法给出完整可信协方差时，矩阵标记为不可用并保留原因；不输出伪造的零矩阵。

### 6.2 联合拟合

先在共同最优点获得全局坐标下的残差、Jacobians 和模式统计输入，再分析共享参数的信息。
服务组合层传递数值证据或具体 callable，分析层不反向导入拟合层。

- 不同起点的参数标准差只作为搜索稳定性证据，绝不写入统计 `parameter_sigma`。
- 对每个数据集执行自相关和系统性残差诊断，携带数据集标识。
- 只要成员存在显著模型不匹配，联合结果不能靠候选收敛一致被标为“可信”。
- 联合 bootstrap 对成员数据按各自噪声模式重采样，并在每次重采样中重新拟合整个共享问题。
- 未执行的诊断与“已执行且未发现问题”分别表示。

### 6.3 报告与导出

报告保存协方差方法、区间类型、置信水平（适用时）、不可辨识参数及不可用原因。
GUI、项目保存、表格与 ORSO 导出使用相同语义；不可用误差不转换成零。

## 7. Profile 与区间

- 默认稳健模式的经验 profile 是损失容差诊断，明确标记，不写成 95% 置信区间。
- 满足无先验、无经验再权重及常规正则条件的 Gaussian／Poisson profile，使用
  单参数 `Delta(-2 log L) = chi2.ppf(0.95, 1)` 的渐近区间，并记录其适用条件。
- 有先验、边界、不可辨识或明显模型失配时，不沿用上述覆盖率承诺；使用明确标识的支持区间或重采样区间。
- 正式 bootstrap 百分位区间至少使用 200 个成功样本；8 次探索性重采样不能输出冠以 95% 的正式区间。
- 快速自动拟合不被强制附加昂贵 bootstrap；未请求／未完成统计区间时明确显示状态。
- profile 网格精度不再借用 bootstrap 样本数隐式控制，二者配置和工作量各自明确。

## 8. 性能优化

### 8.1 仅拟合点进入内环

完整原始轴用于最终结果、导出和预览；优化器的 scalar、residual、Jacobian 只计算拟合点。
最终候选仍通过完整发布求值，保持完整曲线和物理诊断，不用稀疏内环数组冒充完整结果。

验证包含相同拟合点的两种存储方式：完整数据加遮罩，以及仅存储选中点。
它们的目标、残差和 Jacobian 必须一致；通过实际物理求值点数验证工作量缩减。
墙钟测试单独报告中位数，不把审计中约 9 倍的个例写成通用承诺。

### 8.2 联合求解共享缓存

联合 residual／Jacobian 回调共享同一点的数值系统结果。
沿用线程隔离、输入值比较和数组所有权保护；不建立跨任务、跨问题的全局缓存。
用调用次数测试证明减少重复工作，用并发测试防止取错点或数组被 SciPy 修改。

## 9. 渐进网格与搜索预算

- 粗网格下限沿用 128 点，端点和显著尖峰受保护。
- 根据可检测的条纹数，优先满足每个条纹至少 8 个采样点；按 128、256、512、完整网格逐级提升。
- 原始点数低于某级时直接使用完整有效网格，不插入伪观测点。
- 粗筛保留前 8 个成本／结构多样性候选，用完整目标复核后才作关键淘汰。
- 相对差使用 `abs(J_coarse - J_full) / max(abs(J_full), 1e-12)`。超过 5% 时提升网格并重新筛选。
- 若粗筛第一名不再是完整复核第一名，且完整成本差超过 `max(0.02 * abs(J_full_best), 1e-12)`，同样提升网格。
- 先验及区域语义来自完整上下文，粗网格只近似数据项。
- 每条保留谱系至少获得一次局部精修。连续三代最优目标的相对改善均小于 `1e-4`，且没有新增单位空间距离至少 `0.05` 的候选时，允许结束该段全局搜索。
- 回收的预算优先给完整目标更优且尚未获得追加预算的不同谱系，成本相同时按候选 ID 排序；每条谱系每轮只分配一份，然后重新比较。
- 所有分配受已声明的总 nfev 上限约束；网格复核的额外物理求值单独计数，不隐藏在优化器 nfev 之外。
- 停止理由、实际网格、预算分配、随机种子和候选来源进入检查点证据；同种子重跑及暂停恢复可重放。
- 保留现有多起点搜索思想，不将四个起点一致收敛当成全局最优或物理可信的证明。

## 10. API、GUI 和文件边界

- Python 对外入口仍为 `xrr_fitter.api`。
- 噪声模式可通过公开配置选择、保存和重载，CLI 与 GUI 显式展示当前模式及输入要求。
- 模式或算法版本变化必须使旧数值证据、工作缓存和检查点失效，不复用旧结论。
- 本次没有旧项目兼容需求，版本错误直接返回明确错误，不增加迁移代码。
- UI 改动仅限模式选择、诊断和不确定度语义，不与独立 GUI 重设计工作交叉修改视觉框架。

## 11. 分批交付边界

1. 版本身份、约束尺度导数和统一目标的数值核心。
2. Gaussian／Poisson 残差、导数、输入预检及单／联合一致性。
3. 单／联合统计证据、残差诊断、协方差与正式区间。
4. 拟合点内环及联合同点缓存。
5. 渐进网格、完整目标复核及确定性预算分配。
6. 模式入口、报告／项目／导出接线、文档与全链路验收。

各批都先取得针对性 RED，再完成 GREEN 和相关回归；不以修改断言掩盖退化。
跨批共享的 `evaluation`、`model` 或报告接口串行修改；只有无共享写集的任务可以并行。

## 12. 验证与完成标准

- 将审计中的错误可信度、错误协方差、先验梯度和粗网格先验变化转为自动回归。
- 数值导数覆盖自由、共享、约束、边界附近及三种噪声模式；比较 scalar 梯度与残差 Jacobian 链的一致性。
- 已知误差模型下，重复独立观测的信息应相加，标准误按预期缩小；不可辨识参数不产生零误差声明。
- 噪声模式变更必须实际改变数据项、导数与推断；非法输入在优化前失败。
- 不放宽已有物理参照容差，运行 refnx、ORSO、单／联合拟合、GUI 与导出回归。
- 运行既有完整慢速合成恢复集。另设可显式运行的区间覆盖率实验，用至少 200 个固定生成种子，
  按二项分布检验报告名义 95% 区间的经验覆盖率；保留失败例，不挑选种子。
- 覆盖率实验不自动扩大原 CI 门禁；本轮本地验收单独执行并记录。
- 性能同时记录求值点数、系统求值次数、阶段 nfev 和墙钟中位数；性能收益必须伴随数值一致性证据。
- 运行 `tools/verify.py` 相关模式与完整 `tools/check_radon.py`；报告和缓存位于仓库外。
- 现有 hygiene 要求 `.git` 为目录，不接受 linked worktree 的 `.git` 文件。涉及这一门禁的验证在同提交的临时普通 Git clone 中执行；不为本任务放宽 hygiene。
- 真实数据只在输入存在且满足既有验收条件时运行，未运行明确记录，不用合成数据替代真实验收。
- 不自动 push、合并其他分支、创建 release 或删除用户文件。

## 13. 本设计的核对结果

全部 C1–C6 和 O1–O5 均有对应设计及验收条件。
没有旧版本兼容实现，没有新生产依赖，没有跨领域反向导入。
正式区间与探索性 profile、搜索稳定性与统计误差、原始计数与归一化强度已明确区分。
