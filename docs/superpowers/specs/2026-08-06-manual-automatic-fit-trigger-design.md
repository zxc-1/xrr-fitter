# 手动触发自动拟合设计

## 目标

自动批次导入只负责解析文件、创建数据集和生成待检查的自动结构。导入成功后不启动
拟合进程；操作者检查或修改膜层、基底、自动 SiO2 和参数后，显式点击现有“自动
拟合”按钮才开始运行。

## 交互流程

1. 操作者导入一个或多个文件。
2. 有效文件按现有规则创建数据集，自动状态保持 `PENDING`；失败文件继续显示在导入
   失败表中。
3. 工作台发布导入后的项目并更新数据集、结构和拟合 readiness，但不创建 worker、
   不显示运行进度，也不改变当前工作区布局。
4. 操作者检查或编辑结构与参数。
5. 操作者点击现有“自动拟合”按钮。按钮调用当前
   `preflight_automatic_fit()` / `start_automatic_fit_job()` 链路，并按现有无批次过滤
   的合同运行项目中全部可运行自动数据集。因此操作者可以连续导入和检查多个批次，
   再统一启动。

## 代码边界

- 删除仅用于导入后自动启动的 `automatic_fit_requested` 信号和工作台连接；
  `DataPanel.import_paths()` 仍发布 `datasets_imported` 和 active-dataset 变更。
- `FitPanel.start_automatic_fit()`、worker/API 协议和拟合算法保持不变。
- 不增加确认弹窗、自动启动偏好或新的持久化字段。

## 失败与状态

- 部分导入失败不影响有效数据集进入 `PENDING`。
- 膜层结构有误时，操作者可在拟合前修改；相关失效规则继续把受影响组保持为
  `PENDING`。
- readiness 不满足时，现有按钮禁用或显示现有 preflight 原因，不启动 worker。

## 验证

- GUI 单元测试证明有效导入不会请求自动拟合，且数据集仍成功发布并保持
  `PENDING`。
- GUI 集成测试证明导入后没有调用 `start_automatic_fit_job()`；显式点击“自动拟合”
  后只调用一次，并传入当前项目。
- 保留 FitController、自动 worker、失败恢复和现有按钮启动测试。
- 更新用户指南，将“导入后立即拟合”改为“检查后点击自动拟合”。

## 非目标

- 不改变文件名解析、材料识别、基底选择、SiO2 策略、批次路由或性能预算。
- 不修改专家拟合入口、自动拟合数值结果、checkpoint 或导出行为。
