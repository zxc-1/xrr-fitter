# XRR 快速全自动拟合设计

- 日期：2026-08-04
- 状态：书面复核通过，进入实施规划
- 适用范围：桌面 GUI、单数据集拟合、同批多点联合拟合

## 1. 背景与目标

当前 GUI 虽然提供“一键拟合”，正常使用仍要求用户确认光路、初始化结构、处理氧化层、选择拟合模式并理解参数设置。默认拟合还把点估计搜索和完整 profile 不确定性分析串成一个完成条件。

本次实测基线为 Apple Silicon、单层、520 个拟合点和 8 个自由参数：

- 真实 GUI 链路总耗时为 127.21 秒；
- 固定 seed、绕过批处理 progress 缓冲后的总耗时为 95.03 秒；
- A-E 搜索和 basin recovery 在约 19.8 秒内完成；
- 随后的全参数 profile 分析约占 75.2 秒。

因此，本设计的目标不是简单压低优化器迭代数，而是提供以下完整工作流：

1. 用户选择文件后，系统从文件名构建结构并自动开始拟合。
2. 单文件自动独立拟合；同批同结构的多点数据自动联合精修。
3. 不知道配比和密度的多元材料直接拟合有效 X 射线 SLD。
4. 常规数据快速结束；只有质量证据异常时才增加搜索或运行定向 profile。
5. 结果直接回答各点和各层的厚度、粗糙度、材料散射性质及批次均匀性。

## 2. 明确不做的范围

- 本轮不解析文件名中的点位坐标，也不绘制空间分布图。结果先按稳定文件顺序显示。
- 不从未知多元材料代号伪造化学计量比或质量密度。
- 不自动导出文件。现有导出能力保留在高级入口，但不参与自动拟合完成条件。
- 不删除结构编辑、专家参数或手动拟合能力；它们只退出默认路径。
- 不为提速新增第二套物理模型、近似反射率引擎或静默降级求解器。

## 3. 文件名与结构合同

### 3.1 文件名语法

文件 stem 的最后一个空格分隔段使用：

```text
<样品标识> <基底侧膜层>+...+<表面侧膜层>
```

例如：

```text
S300-1_250904-2 Si3N4+Si+Zr.xy
```

表示有限膜层从基底侧到表面侧依次为 `Si3N4 / Si / Zr`。内部 `StructureSpec.components` 仍按表面到基底保存，因此解析器负责唯一一次顺序反转。

`A+B+C` 中的每一项都是有限膜层，不包含基底。

### 3.2 基底与自然氧化层

- 默认基底为 Si。
- 当最左侧膜层为 Si 时，基底不能从已确认的命名规则唯一确定；导入时按同结构组询问一次基底。
- 选定 Si 基底后，系统在基底与最底层膜之间自动加入 SiO2 自然氧化层。
- 若基底相邻膜层已经是精确公式 `SiO2`，不得重复插入。
- 自动 SiO2 沿用版本化氧化层规则：名义密度 2.20 g/cm3、初始厚度 10 A、厚度边界 2-50 A、名义密度锁定。
- 氧化层厚度仍是点位局部参数，不能因联合拟合而强制相同。

### 3.3 解析失败

缺少材料段、存在空 token 或材料段无法建立结构时，只阻止对应文件。界面必须显示文件名和可执行恢复动作：改名重试或进入手动结构编辑。不得猜测层序，也不得让一个坏文件阻止其他有效文件。

## 4. 材料建模

### 4.1 已知材料

元素或材料库中具有明确化学式和名义密度的材料继续使用 formula-density 模型。拟合参数保留 `density_scale`，结果显示：

- 名义密度；
- 拟合相对密度；
- `拟合密度 = 名义密度 * density_scale`，单位 g/cm3；
- 对应波长下的拟合 SLD。

### 4.2 未知配比材料

`CrSiC`、`SiCMo` 等不含真实元素比例的名称视为材料代号。系统不得把字符形式解释成 1:1:1 配比，也不得要求用户为大量点位填写配比和密度。

未知代号使用 `MaterialSpec.sld_override_a2` 的直接 SLD 模型：

- SLD 实部自动参与拟合；
- 初值来自确定性的物理范围候选和数据特征，不依赖随机默认值；
- SLD 吸收部初始锁定；只有系统残差、候选分歧或明确的目标改进证据触发时才释放；
- 同一联合组内的同名材料共享有效 SLD；
- 不同导入批次不得把上一次拟合 SLD 当作新的材料真值静默复用。

结果显示有效 SLD和波长相关的有效电子密度。质量密度位置明确显示“配比未知，无法换算”，不得输出虚假的 g/cm3 数值。

## 5. 自动分流

一次文件选择操作形成一个导入批次。每个有效数据集根据以下签名分组：

- 解析后的有序膜层代号；
- 确认后的基底；
- 光源和仪器测量预设；
- 影响物理模型的结构模式。

路由规则固定为：

1. 组内只有一个数据集时，运行单样品自动拟合。
2. 组内有多个数据集时，运行并行预拟合和联合精修。
3. 一次导入包含不同签名时，拆成多个独立组；单条组和多条组分别走对应路径。
4. 不得仅因“同时导入”就联合物理结构不同的数据。

首次使用或切换仪器时，用户选择一次测量预设。后续导入复用显式保存的预设，不在每批重复询问，也不从曲线静默猜测波长或光路。

## 6. 单样品自动拟合

单样品继续复用现有 A-E 全局到局部搜索、解析 Jacobian、候选聚类、checkpoint 和 basin recovery。自动编译层厚、粗糙度、材料参数、背景、尺度、角度偏移和分辨率边界。

完成点估计后始终运行快速质量门槛；只有门槛触发时才增加确定性搜索预算或运行定向 profile。不得用完全跳过质量分析的方式满足速度指标。

## 7. 同批多点联合拟合

同批数据来自同一次制样的多个测量点，目标是测量厚度均匀性。联合拟合必须利用共同材料信息，但不能抹掉点位差异。

### 7.1 第一阶段：并行预拟合

- 所有点在一个全局 CPU 预算内并行预拟合。
- 每个点产生完整候选和快速质量证据。
- 无有效候选、物理无效或残差明显异常的点先标记为隔离点，不进入首轮联合共识。
- 隔离是可审计状态，不是删除数据。

### 7.2 第二阶段：联合精修

首轮联合精修使用预拟合优质候选作为初始化：

- 同名材料的 `density_scale` 或直接有效 SLD 硬共享；
- 各层厚度始终为点位局部参数；
- 背景、尺度、角度偏移和足迹参数保持点位局部；
- 粗糙度先共享；若共享模型引入系统残差或显著恶化某点目标值，自动改为点位局部后重做精修。

联合结果完成后，隔离点使用该组已确定的材料 SLD 重新独立拟合。重试通过质量门槛后可重新计入统计；未通过时保留结果并标记“需复核”。

## 8. 自适应质量分析

每个单样品或联合投影结果始终检查：

- 多个搜索种子是否收敛到等价候选簇；
- 参数是否命中现有版本化边界阈值；
- Jacobian/covariance 是否出现现有强相关阈值 `>=0.95`；
- 拟合残差是否满足现有 ACF 规则：前 `min(20, N//5)` 个非零 lag 中至少两个超过 `3/sqrt(N)`；
- 是否存在非有限值、物理诊断或无有效候选；
- 联合共享是否对单点造成系统性拟合恶化。

处理顺序固定为：

1. 候选分歧或未收敛先增加有界搜索预算。
2. 联合共享不一致先释放对应的可释放共享参数。
3. 边界、强相关、多解或系统残差仍存在时，只对相关的厚度、SLD、粗糙度或仪器参数运行定向 profile。
4. 确定性工作预算耗尽后仍未通过门槛，返回最佳有效结果并标记“需复核”，不得标记“通过”。

全参数 profile 不再是每次拟合的无条件步骤。Profile 仍用于识别不可辨识、多解和参数区间，只在证据需要时运行。

## 9. 性能与准确性目标

参考平台为 Apple Silicon，常规输入为 1-4 层、最多 650 个拟合点：

- 单样品常规完成目标：20 秒内；
- 2-4 点同结构批次联合精修目标：45 秒内；
- 疑难数据自适应升级目标：60 秒总工作预算内。

算法使用确定性的求值、迭代、候选和 profile 数量上限。上述墙钟值是参考平台验收目标，不作为不同机器上会改变数值结果的强制杀进程 deadline。达到工作预算后按质量状态诚实返回。

现有合成恢复门槛不得下降：

- 厚度和周期相对误差：中位数 <=2%，P95 <=5%；
- 相对密度相对误差：中位数 <=3%，P95 <=8%；
- 粗糙度绝对误差：中位数 <=1 A，P95 <=3 A；
- 模型错误和歧义数据不得被错误标记为通过。

新增验收覆盖：

- 未知材料有效 SLD 恢复；
- 同批公共 SLD 和点位局部厚度恢复；
- 已知厚度变化下的批次均匀性统计；
- 异常点隔离、重试和统计成员身份。

## 10. 结果与状态

默认结果页面显示：

- 每个点的实测曲线、拟合曲线和残差；
- 每层厚度、粗糙度、有效 SLD；
- 已知材料的名义密度、相对密度和拟合质量密度；
- 未知材料的有效 SLD、有效电子密度和不可换算质量密度说明；
- 每层批次均值、最小值、最大值、总体标准差、CV 和相对极差；
- 参与统计和被隔离的点位清单。

统计定义固定为：

- `CV = population_std / mean * 100%`；
- `relative_range = (max - min) / mean * 100%`。

只有通过质量门槛且完成对应联合精修的点进入正式批次统计。其他点仍显示在表中，并明确说明未计入原因。

状态语义为：

- `通过`：自动流程完成且所有适用质量门槛通过；
- `精修中`：已有预拟合曲线，仍在联合、自适应搜索或定向 profile；
- `需复核`：存在最佳有效结果，但工作预算耗尽后仍有未解除证据；
- `失败`：没有可发布的有效候选。

## 11. GUI 与错误恢复

默认路径为“选择文件 -> 自动拟合 -> 查看结果”。结构和专家参数保留在高级入口。

正常流程仅允许以下交互：

- 首次使用或切换仪器时选择测量预设；
- 最左膜层为 Si 时按组选择实际基底；
- 数据列无法可靠识别时，只为异常文件选择列映射；
- 文件名结构无法解析时，改名重试或进入手动编辑。

运行时行为：

- 一个文件损坏或失败不阻塞其他组；
- 完成一个点即发布其可查看状态，不等待整个导入批次才更新界面；
- 取消保留此前有效结果和兼容 checkpoint；
- source hash 改变只失效对应数据及受其影响的联合结果；
- 不允许联合失败静默回退并伪装为联合成功。

## 12. 代码边界

实现遵循现有 `src/` 和公共 API 规则：

- `services.datasets`：文件名解析、导入批次身份和数据集创建；
- `services.materials`：已知材料与未知 SLD 材料声明；
- `services.structures`：基底选择、SiO2 自动插入和结构校验；
- `fit` / `analysis`：现有求解、候选、质量证据和定向 profile；
- `services.fitting`：单数据集自动拟合组合；
- `services.batch`：按签名分组、CPU 预算、并行预拟合、联合精修和异常隔离；
- `gui.data` / `gui.fitting` / `gui.results`：默认自动路径、进度和结果汇总；
- `xrr_fitter.api`：所有新增受支持操作的唯一公共入口。

不得新增 legacy import shim、双实现、静默 fallback 或绕过 `xrr_fitter.api` 的 GUI 业务调用。
